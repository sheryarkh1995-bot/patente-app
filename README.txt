PHONE INSTALLATION
A PWA must be served over HTTPS (or localhost) to install properly. Upload this folder to any static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, etc.). Then:
- iPhone/iPad Safari: Share -> Add to Home Screen
- Android Chrome: menu -> Install app / Add to Home screen

DESKTOP TEST
From this folder run:
  python -m http.server 8000
Then open http://localhost:8000

V1 note
This bundle contains only Quiz 01. Future 5-quiz batches can be added as data files without redesigning the interface.
